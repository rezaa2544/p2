هر پیکان «الف ← ب» یعنی الف برای محتوا/تصمیم به ب وابسته است:

```text
SUPERVISOR_BRIEF ← (حاکم بر همه: اصل هشتم، مرج با تأیید ناظر)

ROADMAP ← منبع همه؛ به آن وابسته‌اند:
  NATIONAL_ROADMAP_PROGRESS (تابلوی اجرا)
  NATIONAL_ROADMAP_ARCHITECTURE_ADDENDUM (الحاقیهٔ معماری)
  همهٔ اسناد موج‌ها (§۲.۸)

NATIONAL_ARCHITECTURE (چتر) ← جمع‌بندی و ارجاع به:
  DATABASE_ARCHITECTURE · AUTHORIZATION_MODEL · SYNC_PROTOCOL · OBSERVABILITY
  SECURITY_MODEL · DISASTER_RECOVERY · MIGRATION_GUIDE · PRODUCTION_RUNBOOK
  INCIDENT_RESPONSE · CAPACITY_MODEL · جدول اسناد §۳۰ (۱۴ سند)

CAPACITY_MODEL ← مبنای اعداد برای:
  LOAD_TEST_PLAN ← LOAD_TEST_RESULTS (خروجی اجرا؛ قالب آماده)
  WAVE18_LOAD_TEST_PLAN · PILOT_ROLLOUT_PLAN (یادداشت مقیاس)

PRODUCTION_READINESS_CHECKLIST ← وضعیت ۴۰ معیار؛ به آن وابسته‌اند:
  P0_BLOCKER_TRACKER (شش مانع پ0 از اینجا استخراج شده)
  GO_LIVE_PACKAGE §۸ (مانع‌های باز)

P0_BLOCKER_TRACKER ← وابسته به:
  GO_LIVE_PACKAGE §۵/§۸ · PRODUCTION_READINESS_CHECKLIST · PR_MERGE_PLAN · HANDOFF

GO_LIVE_PACKAGE ← وابسته به:
  PRODUCTION_READINESS_CHECKLIST · RELEASE_NOTES · LOAD_TEST_RESULTS
  DR_RUNBOOK (بازگشت) · INCIDENT_RESPONSE (قالب ارتباط) · PILOT_ROLLOUT_PLAN §۹

PILOT_ROLLOUT_PLAN ← وابسته به:
  GO_LIVE_PACKAGE (پیش‌شرط گو) · P0_BLOCKER_TRACKER · INCIDENT_RESPONSE (شدت‌ها)
  PRODUCTION_RUNBOOK (کشیک) · CAPACITY_MODEL · LOAD_TEST_RESULTS

DISASTER_RECOVERY ← DR_RUNBOOK · RELIABILITY_DR_PLAN · HA_POSTGRES · HA_REDIS
OBSERVABILITY ← OBSERVABILITY_DEPLOYMENT · PRODUCTION_RUNBOOK §۳ · INCIDENT_RESPONSE
DOCS_INDEX (همین سند) ← نمای همهٔ بالا + خروجی سلامت: DOCS_HEALTH_REPORT
```
