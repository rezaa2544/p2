# طرح پورت شاخه `fix/arch-review-wave2` به main (بررسی چت ۳)

**تاریخ:** ۱۹/۰۶/۱۴۰۵ · **نویسنده:** چت ۳ · **وضعیت: طرح — بدون تغییر کد**
**مبنا:** `origin/main` در `15ae1bd` · نوک wave2 در `4679a75` · مبنای مشترک `eddddfa`.

## خلاصه

برخلاف فرض اولیه («۱۴۶ کامیت عقب و نیازمند پورت دستی»)، هر سه کامیت wave2 (با فاصلهٔ واقعی
**۲۱۹** کامیت) **عملاً روی main هستند** — W1 و W2 بایت‌به‌بایت، و W3 با پیاده‌سازیِ معادل
(در یک مورد با نام‌های متفاوت) یا سوپرمجموعه (اسپلیت کامل ۱۳ ماژوله به‌جای پایلوت ۳ گروهی).
**پورت کدی لازم نیست.** تنها خلأ، یک سطر سند (AD ‏۸۵.3‏) است. این طرح به‌جای دستور پورت،
پروتکل راستی‌آزمایی + بازنشستگی شاخه می‌دهد.

## ۲. چالش‌ها (بازتعریف‌شده)

1. **چالش فرضی W3 منحل شد:** `19-actions.js` قدیمی روی مین نیست (۱۳ فایل `19-actions-*.js`)،
   ولی چون اسپلیت کامل انجام شده، «پورت معادل» قبلاً رخ داده — چیزی برای بازنویسی نمانده.
2. **ریسک واقعی: پورت کورکورانه = پسرفت.** اعمال مکانیکی diff wave2 روی مین، نسخه‌های جدیدتر
   (R-سخت‌سازی‌ها، فاز ۲) را با نسخه‌های قدیمی دور ۸۵ رونویسی می‌کند.
3. **خلأ پوششی جزئی:** تست `actions-split` wave2 قابل‌پورت نیست؛ باید مطمئن شد پوشش معادل
   برای دیسپچ ۱۳ ماژوله هست (هست: smoke ‏۵۴۷ + سئوت‌های ویژگی + `check-authz` + تست فریز W4 —
   به §۴).

## ۳. راه‌حل پیشنهادی (به‌جای پورت)

2. **سند (اختیاری، ۱ خط):** افزودن سطر AD ‏۸۵.3‏ به `docs/ARCHITECTURE_DECISIONS.md` مین با

   main (phase 2)» بازنشسته و حذف شود تا دوباره کاندیدای پورت نشود.
