## ۱. مسئله به زبان ساده

تا پیش از این قرارداد، هیچ‌جا نوشته نشده بود که `npm test` دقیقاً چه چیزی را اجرا

اندازه‌گیری‌نشده** است که به‌راحتی به ادعای اشتباه تبدیل می‌شود.

## ۳. قرارداد

### ۳.۱ آنچه `npm test` تضمین می‌کند

```
npm test  ⇒  node tests/run.js  &&  node --expose-gc --max-old-space-size=2048 tests/smoke.js
```

- `tests/run.js` یک سوئیت **ساختاری/یکپارچگی build** است، نه orchestrator. هیچ فایل
  تست دیگری را spawn یا require نمی‌کند. (تأیید: `grep` روی `require(`/`spawn`/`execSync`.)
- `tests/smoke.js` سوئیت دودِ زمان‌اجراست.
- `npm test` **Node ≥ ۲۲ را اجباری می‌کند** و روی نسخهٔ قدیمی‌تر عمداً قرمز می‌شود
  (`tests/run.js` خطوط ۱۴–۲۲) تا skipِ پنهان رخ ندهد.

**بنابراین: `npm test` سبز = این دو سوئیت سبزند. نه بیشتر.**

### ۳.۲ آنچه CI تضمین می‌کند

CI مرجعِ واقعیِ پوشش است، نه `npm test`:

- `node.js.yml` — ۳۰ ارجاع تستی، با سرویس‌های واقعی `postgres:17` و `redis:8`.
- `security.yml` — ۶ ارجاع تستی (secret-scan، WAF و غیره).

هیچ‌کدام از این‌ها با اجرای محلیِ `npm test` پوشش داده نمی‌شوند.

### ۳.۳ قواعد الزام‌آور

1. **هیچ تستی برای سبزشدن حذف یا skip نمی‌شود.** اگر تستی قرمز است، یا رفع می‌شود یا
   به‌عنوان یافتهٔ باز ثبت می‌شود.
2. **هر ارجاع تستی در workflowها باید روی دیسک وجود داشته باشد.** ارجاع مرده =
   گیتِ خاموش (توسط P4 بررسی می‌شود).
3. **سقف تست‌های اجرانشده = `485` — دقیقاً برابر اندازه‌گیری جاری، بدون هیچ حاشیه.** کاهشش آزاد است؛ افزایشش CI را قرمز می‌کند. یعنی
   افزودن فایل تستی که هیچ‌جا اجرا نمی‌شود باید تصمیمی آگاهانه و مستند باشد.
4. **هیچ گزارشی حق ندارد بنویسد «همهٔ تست‌ها سبزند»** مگر با استناد به run id مشخص و
   شمارش واقعی.

## ۵. آنچه این قرارداد حل **نمی‌کند**

این یک **قرارداد** است، نه پوشش تست. ۴۸۵ فایل تستِ سطح‌بالا همچنان در هیچ اتوماسیونی
اجرا نمی‌شوند و بعضی‌شان قرمزند. بستن آن شکاف یک تصمیم مالکانه دربارهٔ زمان اجرای CI
و دسته‌بندی سوئیت‌هاست:

**BLOCKED — OWNER DECISION REQUIRED:** آیا یک lane جدید (مثلاً nightly) برای اجرای
دسته‌جمعی این ۴۸۵ فایل ساخته شود، یا زیرمجموعه‌ای از آن‌ها رسماً «آرشیو/غیرفعال» اعلام
شود؟ تا زمان آن تصمیم، این سند وضعیت را صادقانه ثبت می‌کند و از ادعای اضافی جلوگیری
می‌کند.
