## آنچه در مخزن بود

مخزن فقط شامل **یک فایل `school.rar`** (۲.۱ مگابایت) بود — نه سورس باز‌شده. پس از استخراج:

**پروژه‌ای کاملاً متفاوت با ورک‌اسپیس من:** نسخهٔ **سروری** پایش با پشتهٔ کامل:

| بخش | جزئیات |
|---|---|
| فرانت‌اند | React 19 + Vite 8 + React Router 7 — **۳۶ صفحه `.jsx`** |
| بک‌اند | Express 5 + better-sqlite3 + Postgres — **۳۳ فایل سرور** |
| امنیت | bcrypt، JWT + refresh چرخشی، helmet + CSP، zod، rate limit |
| زیرساخت | Dockerfile، docker-compose (dev/prod)، nginx.conf، GitHub Actions (CI + backup) |
| تست | **۱۶ فایل فاز** + bench + ui-smoke + mobile + standalone |
| حجم کد | ~۱۴٬۶۰۰ خط JS/JSX |
| مستندات | SPEC.md (۳۱۶)، ROADMAP.md (۳۵۲)، README.md (۱۵۷)، docs/SCALE-SECURITY.md (۱۸۴) |

⚠️ چهار فایل هنگام استخراج خراب بودند (`index.html`, `Dockerfile`, `server/seed.js`, `src/pages/Login.jsx`) — احتمالاً به‌خاطر فشرده‌سازی solid در RAR. باقی ۱۸۱ فایل سالم خوانده شد.

## یافتهٔ اصلی: آیا چیزی جا انداخته‌ام؟

**نه.** بررسی کردم و نتیجه روشن است:

فایل مبنای کار من — `uploads/پایش-سامانه-مدیریت-مدرسه (9).html` — این قابلیت‌ها را **از ابتدا نداشته**. با جستجوی متنی مستقیم در آن فایل تأیید شد:

```
❌ چرخه تحصیلی   ❌ رشد مدرسه      ❌ افت تحصیلی
❌ جلسات اولیا   ❌ فرم‌های رسمی   ❌ پیامک
❌ ویزارد اکسل   ❌ DecompressionStream
```

پس این‌ها **حذف‌شده توسط من نیستند؛ هرگز در نسخهٔ ۹ نبوده‌اند.** ROADMAP مخزن نشان می‌دهد که این‌ها در نسخهٔ تک‌فایلیِ **دیگری** (فایل `پایش-سامانه-مدیریت-مدرسه.html` بدون شمارهٔ ۹، که در `tests/standalone.mjs` به آن ارجاع شده) پیاده شده بودند — نسخه‌ای که در اختیار من قرار نگرفته.

## درس مهم از نسخهٔ سروری

سند `docs/SCALE-SECURITY.md` مخزن، همان مسیری را رفته که من مستقل به آن رسیدم — و این هم‌راستایی ارزشمند است:

| موضوع | نسخهٔ سروری | کار من |
|---|---|---|
| ایندکس | ۳۹ ایندکس ترکیبی SQL (`ensureIndexes()`) | ۸ ایندکس `Map` سمت کلاینت |
| محدودسازی داده | `scopeOf(req)` سمت سرور | `scopeDescriptor()` قرارداد |
| اداره = فقط تجمیعی | ✅ پیاده | ✅ در قرارداد |
| سقف نتایج | `limit` حداکثر ۲۰۰ | `SCOPE_LIMITS.pageSize` |
| بهبود داشبورد اداره | ۶٬۰۵۰ms → ۱۴۸ms | ۱۴ پیمایش → ۱ |

**نکتهٔ قابل‌توجه:** نسخهٔ سروری برای «۳ میلیون کاربر» طراحی شده و به همان نتیجه رسیده که من رسیدم — معماری جواب می‌دهد، زیرساخت باید پله‌پله رشد کند.

**آنچه از آن سند باید به کار من اضافه شود:**
- ورود دومرحله‌ای (OTP) برای نقش‌های پرقدرت
- `audit_log` برای عملیات حساس
- رمزنگاری ستون کد ملی
- پارتیشن‌بندی `attendance`/`grades` در مقیاس ۵ میلیون
