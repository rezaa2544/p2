# رفع ابهام نگاشت D.1–D.4 (برای تصمیم چت ۴)

**تاریخ:** ۱۸/۰۶/۱۴۰۵ · **نویسنده:** چت ۳ (استندبای فعال) · **وضعیت: پیشنهاد — تصمیم نهایی با چت ۴**
**مبانی:** `docs/D_OFFICE_LEVEL_ANALYSIS.md` چت ۱ (شاخهٔ `feat/farnaz-phase1-chat1` در `72392bf`)
+ پرامپت استندبای هماهنگ‌کننده.

## ۱. دو نگاشت کنار هم

| بند | نگاشت چت ۱ (حدسی، مسیر فنی) | نگاشت پرامپت استندبای (مسیر ویژگی) |
|---|---|---|
| D.1 | تحلیل + قفل‌شدن تصمیم سطح/رئیس | — (تعریف نشده) |
| D.2 | دادهٔ نمونهٔ دوسطحی + seed نهایی | **گزارش کارت امتیازی منطقه** |
| D.3 | دامنهٔ سطح‌آگاه + نقش رئیس (کلاینت + سرور) | **اطلاعیه فوری/بحرانی** |
| D.4 | تست‌ها + مستندسازی | **نمای کمبود نیرو** |

این دو نگاشت متعارض نیستند بلکه **دو لایه‌اند**: نگاشت چت ۱ «زیرساخت لازم» و نگاشت استندبای
«ویژگی قابل تحویل» است. هر سه ویژگی مسیر دوم، روی دامنهٔ اداره (`officeScopeSchools`) سوار می‌شوند
و هر سه از همان ۳ شکاف بحرانی تحلیل چت ۱ اثر می‌پذیرند (نبود رئیس، بی‌توجهی دامنه به `level`،
نامحدودبودن سرور).

## ۲. نگاشت نهایی پیشنهادی چت ۳ (برای تأیید چت ۴)

| بند | تعریف پیشنهادی | خروجی قابل آزمون |
|---|---|---|
| D.1 | قفل تحلیل + تصمیم‌های P1–P5 چت ۱ (سطح/رئیس/دامنهٔ سرور/سینک جغرافیا/سید) | سند تصمیم + قاعدهٔ اعتبارسنجی §۵ |
| D.2 | **کارت امتیازی منطقه** (فقط‌خواندنی، کلاینت) — پیش‌نویس: `docs/D2_DRAFT.md` | روت/نما + CSV + سئوت + جهش |
| D.3 | **اطلاعیه فوری/بحرانی** (مدل + نما + مجوز) — پیش‌نویس: `docs/D3_DRAFT.md` | severity + هدف‌گیری + سئوت + جهش + تست سرور |
| D.4 | **نمای کمبود نیرو** (خواندنی + مبنای «موردنیاز») — پیش‌نویس: `docs/D4_DRAFT.md` | نما + تصمیم norm + سئوت + جهش |

**ترتیب پیشنهادی:** D.1 (تصمیم) → P1+P5 (دامنهٔ سطح‌آگاه + سید دوسطحی، پیش‌نیاز هر سه ویژگی)
→ D.2 (بی‌خطرترین: بدون نوشتن) → D.4 (پس از تصمیم norm) → D.3 (حساس‌ترین: انتشار + مجوز + سرور).
نقش رئیس (P2) و دامنهٔ سروری (P3) می‌توانند پس از D.2 بیایند، مشروط بر اینکه D.3 بدون P3
(سرور نامحدود) پذیرفته شود یا نه — این را چت ۴ باید صراحتاً بپذیرد/رد کند.

## ۳. سؤال‌های باز برای چت ۴ (پیش از شروع پیاده‌سازی)

1. آیا نگاشت §۲ تأیید است؟ اگر نه، تعریف دقیق هر بند چیست؟
2. آیا D.3 بدون دامنهٔ سروری (P3) قابل قبول است، یا P3 پیش‌نیاز D.3 است؟
3. مبنای «نیروی موردنیاز» در D.4 کدام است؟ (جدول norm تازه / آستانهٔ نسبت / اعلام دستی مدیر)
4. چه کسی «بحرانی» منتشر می‌کند؟ (هر کارشناس / فقط رئیس — وابسته به P2)
