## ۵. روش‌شناسی

1. **تست-اول-قرمز:** هر رفع باگ (باگ‌هانت‌ها و موج‌ها) ابتدا تست قرمز می‌گیرد، سپس رفع، سپس سبز — شاهد همهٔ رفع‌ها در `docs/BUG_HUNT_REPORT.md`.
2. **تست منفی اجباری برای مجوز:** هر مسیر نوشتن باید ۴۰۳ بیرون‌دامنه داشته باشد (درس اس‌اف-۰۰۷).
3. **جهش برای پیکربندی/مستندات:** تغییر یک‌طرفهٔ متریک/قانون/داشبورد باید سی‌آی را بشکند (ضدرانش سه‌جانبهٔ موج ۱۴).
4. **بدون تضعیف تست برای سبز شدن:** قرمز = توقف مرج، نه حذف چک (قاعدهٔ ناظر).
5. **یافت‌های امنیتی رفع‌شده ⇒ تست رگرسیون ماندگار:** ۲۱ مورد در `docs/SECURITY_FINDINGS_REGISTER.md`.
