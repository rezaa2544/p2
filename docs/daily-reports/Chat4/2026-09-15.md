- **`code-verified`**: Directly present and verified in tracked codebase files (`file:line`).
- **`documented-only`**: Promised or claimed in architecture docs/runbooks without executing code or local test harness.
- **`unsourced`**: Claims (especially around live RTO/RPO/capacity numbers S1–S6) lacking empirical staging or production telemetry.

   - *Status:* **`unsourced`**.  
   - *Reason:* Extrapolated sizing model. Real staging load tests (Wave 18) were performed on a single sandbox box, which explicitly cannot prove national 10M concurrent session scale.
4. **Redis Cluster Automatic Sharding (`docs/REDIS_CLUSTER_SETUP.md`):**  
   - *Status:* **`documented-only`**.  
   - *Reason:* Parsing logic exists in `server/redis.js:106-127`, but no cluster topology compose file or integration test is executed in CI/sandbox.
5. **Failover Client Reconnection Without Restart (`docs/HA_REDIS.md §2`):**
