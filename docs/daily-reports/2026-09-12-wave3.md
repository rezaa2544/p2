# گزارش روزانه Wave 3 — گیت برابری JS↔SQL (چت ۳)

## خلاصه اجرایی

Wave 3 از نظر feature پیاده‌سازی شده بود، ولی قید سرخ §۴ سند `docs/WAVE3_QUERY_PERFORMANCE.md` («گیت برابری بایت‌به‌بایت مسیر JS و SQL») باز مانده بود. این گیت پیش‌تر در همین روز پیاده و با **PR [#96](https://github.com/rezaa2544/p2/pull/96) مرج شد** (merge SHA `f2f0ba1`). در این دور، کل گیت **از صفر روی یک PostgreSQL زندهٔ تازه (۱۸.۴ embedded) بازاجرا و راستی‌آزمایی مجدد** شد + Evidence اجراییِ `EXPLAIN ANALYZE` و benchmark ثبت شد.

**نکتهٔ صداقت مهم:** این دور کد تازه‌ای به گیت اضافه نکرد — گیت از قبل روی `main` بود. کارِ این دور: (الف) بازاجرای مستقل روی کلاستر تازه، (ب) ثبت Evidence اجرایی، (ج) ثبت این گزارش در `docs/daily-reports/`.

## یافته‌های کلیدی

1. **گیت برابری JS↔SQL:** `tests/wave3-parity.js` — **۲۰/۲۰** سناریو (۱۶ سناریوی صفحهٔ اول برای همه نقش‌ها/فیلترها + ۴ پیمایش کامل چندصفحه‌ای با `next_cursor` تا ۲۰هزار ردیف؛ هر چهار خانوادهٔ کرسر: id ASC، id DESC، مرکب date|id)
2. **تست جهش:** `tests/wave3-parity-mutations.js` — **۵/۵ کشته** (ترتیب برعکس، نشت مهار مدرسه، enrichment خراب، کرسر مرکب شکسته، has_more دروغین)
3. **EXPLAIN ANALYZE:** هر ۵ کوئری اصلی صفحه‌بندی **Index Scan** روی جدول پایه — execution time بین ۰٫۰۵۶ms و ۱٫۵۵۵ms (جزئیات پایین)
4. **Benchmark:** صفحهٔ SQL keyset (LIMIT 50) در برابر full-scan مسیر JS روی ۱۵۷k نمره: **۱٫۶۹ms در برابر ۱۹٫۳۳ms ≈ ۱۱×** در این مقیاس. (عدد «۴۸۰×» ادعای این گزارش نیست — آن عدد متعلق به یافتهٔ ۱ سند Wave 3 در مقیاس ۲.۱۹M ردیف روی کوئری `school_id` بدون ایندکس بود؛ این‌جا در مقیاس ۱۵۷k و با ایندکس‌های اعمال‌شده صادقانه ۱۱× اندازه گرفته شد. شکاف با بزرگ‌شدن جدول رشد می‌کند چون مسیر JS خطی است و مسیر SQL لگاریتمی+LIMIT.)
5. **باگ سیدر (خارج از repo) پیدا و رفع شد:** دادهٔ دمو `classes.grade` را فارسی («دهم») نگه می‌دارد ولی ستون PG از نوع INTEGER است؛ سیدر اولیه آن را NULL می‌کرد و سناریوی `classes+grade` قرمز شد — نگاشت «دهم→۱۰…» به سیدر (بیرون از ریپو، `/home/user/pgws/seed-pg.js`) اضافه شد و گیت بدون هیچ تغییری سبز شد. **خود گیت دست نخورد.**

### خروجی EXPLAIN (ANALYZE, BUFFERS) — کوئری‌های صفحهٔ builder (مدیر مدرسهٔ ۱)

```

attendance → Index Scan using idx_attendance_school_date_id           … Execution Time: 0.068 ms
grades     → Index Scan Backward using grades_pkey (+ PK-joins به subjects/users) … Execution Time: 0.429 ms
```
