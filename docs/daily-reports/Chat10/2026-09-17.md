## 3) Defect fixed — Wave-16 DR restore drill was non-hermetic (C10-06 / C10-11)

**Finding.** `tests/wave16-dr.js` declares itself hermetic ("scratch world (hermetic; nothing touches server/data)", line 42). Every check honors that **except** `Td` ("the drill script runs and reports PASS on the seeded store"), which invoked the DR CLI with only `--data-dir` and **no `--store`**:

```
scripts/dr-restore-drill.js --data-dir <TMP/drill-cli>
```

The CLI's default store is `server/data/payesh.json` (`scripts/dr-restore-drill.js:36`), which is **gitignored** (`.gitignore:29 server/data/`) and only exists after a separate `node server/seed.js` step. So on any clean checkout the drill exited with `cannot read store … (ENOENT)`, `Td` failed, and `wave16-dr` went **74/75, EXIT 1** — a false red for the DR restore-drill regression, exactly the kind of flaky reliability signal Chat10 owns.

**Root-cause evidence:**
```
$ git check-ignore server/data/payesh.json                 → server/data/payesh.json   (ignored)
$ node scripts/dr-restore-drill.js --data-dir /tmp/x       → "cannot read store: .../server/data/payesh.json (ENOENT...)"
$ node tests/wave16-dr.js  (clean checkout)                → 74/75, FAIL: "Td ... PASS on the seeded store"
```

**Fix (minimal, +9/-1, `tests/wave16-dr.js` only).** Seed a synthetic store into the suite's existing `TMP` and point the CLI at it with `--store`, reusing the file's own top-level `syntheticStore()` helper. This makes `Td` hermetic and honors the suite's stated "nothing touches server/data" contract for the CLI phase too — no change to production code, `scripts/dr-restore-drill.js`, or `server/dr.js`.

**Verification (clean checkout — `server/data/payesh.json` deleted first):**
```
$ rm -f server/data/payesh.json && node tests/wave16-dr.js  → 75/75 موفق، 0 ناموفق  · EXIT 0  ✅
$ node tests/wave16-dr-mutations.js                          → 11/11 موفق · EXIT 0  ✅  (coverage not weakened)
$ node scripts/dr-restore-drill.js --store <synth> --data-dir <tmp>
                                                            → dr-restore-drill: PASS ✅ · 50 users · WITHIN RTO
```

The mutation companion (`wave16-dr-mutations.js`) still kills all 11 mutants, so the hermetic rewrite did not weaken the assertion — it only removed a hidden dependency on an out-of-tree file.
