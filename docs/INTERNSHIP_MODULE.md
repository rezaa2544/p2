# کارآموزیِ هنرستان (E.2)

> ثبت و پیگیریِ ساعتِ کارآموزیِ سالِ آخرِ فنی‌وحرفه‌ای/کاردانش + گواهیِ پایان.
> بنا شده روی جدولِ موجود (`internships` — هر ردیف یک ثبتِ ساعت)؛ بدونِ جدولِ موازی.

## ۱. نگاشتِ درخواست به موجود

| درخواست | موجود |
|---|---|
| `internships` (شرکت/ناظر/شروع/پایان/کل/لازم/وضعیت) | هر ثبت: `location` (محل)، `created_by/approved_by` (ناظر)، `date`، `hours`، `status` |
| `internship_logs` | خودِ ردیف‌های `internships` (لاگ = ردیف) |
| `required_hours` پیش‌فرض ۲۰۰ | `internshipRequired()` = ۲۰۰، با سقفِ ویژهٔ مدرسه (`schools.internship_hours`) |
| شروع/پایانِ دوره | کمینه/بیشینهٔ `date` ثبت‌ها (نیازی به ستون نبود) |

## ۲. تازه‌های E.2

- **پیشرفت:** بجِ «پیشرفت: X از ۲۰۰» + نوار در کارتِ پرونده.
- **گواهی:** دکمهٔ «🎓 صدور گواهی» (مدیر، فقط دورهٔ تکمیل‌شده، ضدِتکرار) روی
  `certificates` با `type='internship'` + کدِ قطعی؛ اکشنِ `internship-cert`.
- **نمای کلیِ مدیر:** جدولِ همهٔ سالِ آخری‌ها (تأییدشده/لازم، نوار، وضعیت/کدِ گواهی)
  در انتهای صفحهٔ نمرات.
- **داشبورد:** نوارِ «پیشرفتِ کارآموزی» برای دانش‌آموز/ولی (فقط سالِ آخرِ فنی).
- **ثبتِ دبیر:** دکمهٔ «ثبتِ ساعت» برای دبیر هم باز شد (کلاسِ خودش + گاردِ سرور).
- **حذفِ فقط-مدیر:** دبیر از `internships.del` بیرون رفت (+ بازتولیدِ `write-perms.json`).

## ۳. مجوزها

| عمل | دبیرِ مربوطه | مدیر | دانش‌آموز/ولی |
|---|---|---|---|
| ثبتِ ساعت | ✅ (کلاسِ خود) | ✅ | ❌ |
| تأیید | ✅ (دبیرِ مربوطه/سرپرست) | ✅ | ❌ |
| حذف | ❌ (سرور هم رد می‌کند) | ✅ | ❌ |
| گواهی | ❌ | ✅ (فقط تکمیل‌شده) | مشاهده |
| مشاهده | کلاسِ خود | همه | فقط خود/فرزند |

گیت‌ها: هنرستان (`has_workshop` + رشتهٔ فنی/کاردانش) و سالِ آخر (دوازدهم).
