## ۲. نیاز ۱ — همگامی ساعت با سرور

### آنچه از قبل هست

دور ۴۸ قلابش را گذاشت (`46-bell-now.js:63`):

```js
var SERVER_TIME_KEY = 'sms_server_time_v1';
var CLOCK_DRIFT_MIN = 10;               // آستانهٔ هشدار

/* در clockSanity: اگر زمان سرور ذخیره شده باشد، اختلاف سنجیده می‌شود */
if(diff > CLOCK_DRIFT_MIN) return { ok:false, reason:'drift', drift:… };
```

🔴 **ولی هیچ‌جا `SERVER_TIME_KEY` نوشته نمی‌شود** — چون سروری
نیست. قلاب خالی است.

### آنچه لازم است

**گام الف — نوشتن زمان سرور (وقتی سرور آمد):**
```js
/* در 27-sync.js پس از هر پاسخ موفق */
var srvDate = response.headers.get('Date');    // هر پاسخ HTTP دارد
if(srvDate) Store.set(SERVER_TIME_KEY, srvDate);
```

⚠️ **نکتهٔ ظریف:** سرآیند `Date` در **هر** پاسخ HTTP هست، حتی
خطاها. پس نیازی به نقطهٔ پایانی جدا نیست.

**گام ب — رفتار هنگام اختلاف:**

| اختلاف | رفتار |
|---|---|
| < ۱۰ دقیقه | نادیده (تأخیر شبکه طبیعی است) |
| ۱۰ تا ۶۰ دقیقه | ⚠️ هشدار در نوار زنگ، ولی کار ادامه دارد |
| > ۶۰ دقیقه | 🔴 پیش‌گزینش خودکار خاموش + هشدار دائمی |

🔴 **چرا بیش از یک ساعت خطرناک است؟** حضور و غیاب با زمان محلی
ثبت می‌شود. اگر ساعت دو ساعت جلو باشد، غیبت به روز بعد می‌خورد.

### 🔴 نکتهٔ مهم دربارهٔ تقویم

**تقویم شمسی نیازی به همگامی ندارد.** `22-jalali-calendar.js`
تبدیل را **محاسباتی** انجام می‌دهد، نه از جدول. تنها چیزی که
همگامی می‌خواهد **لحظهٔ کنونی** است.

⚠️ **ولی تعطیلات رسمی فرق دارند** — هر سال با فرمان دولت عوض
می‌شوند و محاسباتی نیستند. امروز `calendar` دستی پر می‌شود.
اگر روزی خواستید خودکار شود، منبع بیرونی لازم است (خارج از
دامنهٔ این طرح).

## ۳. نیاز ۲ — روزهای هفتهٔ متغیر 🔴 مهم‌ترین بخش

### مشکل امروز

```js
const DAYS = ['شنبه','یکشنبه','دوشنبه','سه‌شنبه','چهارشنبه'];
                                                    // 01-helpers.js:26
```

پنج روز، **در کد قفل شده**. مدرسه‌ای که پنج‌شنبه هم کلاس دارد
نمی‌تواند برنامه‌اش را وارد کند.

⚠️ **و بدتر:** `46-bell-now.js` تابع `isSchoolDay()` دارد که
`dayIdx <= 4` را روز درسی می‌داند. پس پنج‌شنبه همیشه «تعطیل»
گزارش می‌شود.

### راه‌حل پیشنهادی

```js
/* افزوده به schools */
work_days: [0,1,2,3,4]        // شنبه=۰ … جمعه=۶
```

**چرا آرایه و نه عدد؟** چون بعضی مدارس ممکن است روز وسط هفته
تعطیل باشند (مثلاً مدرسهٔ عشایری). آرایه هر ترکیبی را می‌پذیرد.

**توابع تازه:**
```js
schoolWorkDays(schoolId)      // → [0,1,2,3,4] با پیش‌فرض امن
isSchoolDay(dayIdx, schoolId) // ← امضای فعلی گسترش می‌یابد
dayNameFa(dayIdx)             // ← جدول ۷ روزه به‌جای DAYS پنج‌تایی
```

🔴 **دام سازگاری عقب‌رو:** `DAYS[]` در **پنج جای دیگر** مصرف
می‌شود (`08-dashboard`, `21-exams`, `24-edu-office`×۳). اگر
آرایه را ۷ عضوی کنیم، همه‌جا باید بازبینی شود.

**پیشنهاد امن:** `DAYS` دست‌نخورده بماند (سازگاری) و
`DAYS_FULL` هفت‌عضوی افزوده شود. مصرف‌کننده‌ها تدریجی مهاجرت
کنند.

⚠️ **آزمون نگهبان لازم است:** مدرسه‌ای با
`work_days:[0,1,2,3,4,5]` بسازد و بسنجد که پنج‌شنبه
`isSchoolDay` بدهد و `teacherNowClass` کلاس برگرداند.

### رابط مدیر

در صفحهٔ «راه‌اندازی مدرسه» ⇒ چک‌باکس هفت روز:

```
روزهای کاری مدرسه:
[✓] شنبه  [✓] یکشنبه  [✓] دوشنبه  [✓] سه‌شنبه
[✓] چهارشنبه  [ ] پنج‌شنبه  [ ] جمعه
```

## ۴. نیاز ۳ — تعریف زنگ توسط مدیر

### آنچه هست 🟢

`viewBells()` + `bellSave()` از دور ۴۱ کار می‌کنند. مدیر
`bells` را در منو دارد و می‌تواند ساعت شروع و مدت هر بازه را
تعریف کند. سه الگوی پیش‌فرض هم هست.

### آنچه نیست

**الف) دبیر دسترسی ندارد.** سنجش: `bells` در منوی دبیر **نیست**.

⚠️ **ولی درخواست شما مبهم است:** نوشتید «برای زنگ‌ها یک ادر
ساعت بگذار دبیر خودش تایم را بنویسد». دو خوانش دارد:

| خوانش | معنی | نظر من |
|---|---|---|
| الف | دبیر زمان‌بندی **مدرسه** را عوض کند | 🔴 نه — کار مدیر است |
| ب | دبیر ساعت **کلاس خودش** را ثبت کند | ✅ منطقی، ولی جدا از زنگ مدرسه |

**پیشنهاد من: خوانش ب**، ولی به‌عنوان بخشی از **کلاس جبرانی**
(بخش ۵) نه زمان‌بندی زنگ مدرسه. اگر هر دبیر بتواند زنگ مدرسه را
عوض کند، هرج‌ومرج می‌شود.

**ب) شیفت بعدازظهر جدا نیست.** `schools.shift` سه مقدار دارد
(`صبح`/`بعدازظهر`/`هر دو`) ولی `bell_schedules` **یک رکورد در
هر مدرسه** است. مدرسهٔ دوشیفتی نمی‌تواند دو زمان‌بندی داشته
باشد.

**راه‌حل:** کلید مرکب `{school_id, shift}`.

## ۵. نیاز ۴ — کلاس جبرانی 🔴 از صفر

### چیستی

کلاسی خارج از برنامهٔ هفتگی: بعدازظهر، پنج‌شنبه، یا شیفت مخالف.

### مدل داده

```js
/* جدول تازه: makeup_classes */
{
  id, school_id, class_id, subject_id, teacher_id,
  date,              // '2026-09-12' — تاریخ مشخص، نه روز هفته
  from_time,         // '14:00'  ← دبیر خودش می‌نویسد
  to_time,           // '15:30'
  reason,            // 'جبران غیبت دبیر' | 'تقویتی' | 'آمادگی امتحان'
  location,          // اختیاری
  status,            // 'planned'|'done'|'cancelled'
  created_by, created_at,
  notified_at        // چه وقت اطلاع‌رسانی شد
}
```

⚠️ **چرا `date` و نه `day`+`period`؟** کلاس جبرانی **یک‌باره**
است، نه هفتگی. اگر مثل `schedule` مدل شود، هر هفته تکرار
می‌شود.

⚠️ **`from_time`/`to_time` آزادند** — به زنگ‌های مدرسه بند
نیستند. این همان «دبیر خودش تایم را بنویسد» است.

### اطلاع‌رسانی به همهٔ نقش‌ها

**خواستهٔ صریح شما:** «اطلاع‌رسانی برای همهٔ نقش‌ها».

| نقش | چطور |
|---|---|
| دانش‌آموزان کلاس | اعلان + نمایش در برنامهٔ هفتگی با نشان «جبرانی» |
| اولیای آن‌ها | اعلان + **پیامک اختیاری** |
| دبیر | اعلان تأیید |
| مدیر | در تقویم مدرسه |

🔴 **پیامک اختیاری باشد نه خودکار.** کلاس جبرانی ممکن است چند
بار در هفته باشد؛ پیامک خودکار هم هزینه دارد هم آزاردهنده است.
از همان `notifyRequest` با `kind:'event'` استفاده می‌شود که صف
تأیید مدیر را هم دارد.

⚠️ **تداخل باید بررسی شود:** اگر دبیر همان ساعت کلاس دیگری
دارد، یا دانش‌آموزان کلاس جبرانی دیگری دارند، باید هشدار داده
شود. الگویش در `24-edu-office.js:678` هست (تداخل ساعت دبیر).

### اثر بر نوار زنگ

`currentSlot()` باید کلاس جبرانی را هم بشناسد:

```
🔔 کلاس جبرانی — ریاضی · دهم تجربی (۱۴:۰۰ تا ۱۵:۳۰)
```

⚠️ **اولویت با جبرانی است** — اگر همزمان زنگ عادی و جبرانی
باشد، جبرانی نمایش داده شود چون استثناست.

## ۷. 🔴 هشدارها

| ریسک | توضیح |
|---|---|
| تغییر `DAYS[]` | پنج مصرف‌کننده — سازگاری عقب‌رو لازم است |
| `isSchoolDay` | امضایش عوض می‌شود؛ همهٔ فراخوان‌ها بازبینی شوند |
| حجم `db` | `makeup_classes` کوچک است ولی `db` الان ۴٫۷۲MB از ۵MB |
| ساعت دستگاه | تا سرور نیاید، مبنا همان ساعت کاربر است |
| تداخل جبرانی | باید بررسی شود وگرنه دو کلاس همزمان |

⚠️ **یک نکتهٔ حقوقی:** کلاس جبرانی خارج از ساعت رسمی ممکن است
مقررات آموزش‌وپرورش داشته باشد (اجازهٔ والدین، سقف ساعت). سامانه
باید **ثبت** کند، نه **مجوز** بدهد. متن رابط باید این را روشن
کند.
