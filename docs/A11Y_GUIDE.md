# راهنمایِ دسترس‌پذیری (A11y Guide)

این سند قاعده‌هایِ دسترس‌پذیریِ پروژه را جمع می‌کند تا نقض‌هایِ رفع‌شده برنگردند.
مبنا: WCAG 2.1 سطح AA. راستی‌آزمایی: اسکنِ axe-core رویِ DOM زنده (`tests/a11y-runtime.js`)
+ نگهبانِ استاتیک (`tests/a11y-regressions.js`).

## ۱) نامِ دسترس‌پذیر برایِ هر کنترلِ فرم (axe: select-name, label — critical)

هر `<select>`, `<input>`, `<textarea>` باید یکی از این‌ها را داشته باشد:

1. `<label for="…">` مرئی — گزینهٔ ترجیحی وقتی جا هست؛
2. `aria-label="…"` فارسیِ توصیفی — برایِ کنترل‌هایِ فشردهٔ نوارِ فیلتر؛
3. `aria-labelledby` به شناسهٔ متنِ مجاور.

قاعده‌ها:
- متنِ برچسب باید «چه چیزی انتخاب می‌شود» را بگوید، نه نوعِ کنترل: «انتخاب کلاس» ✅، «سلکت» ❌.
- اگر کنترل در حلقه ساخته می‌شود، برچسب باید نمونه را یکتا کند —
  نمونه: چک‌باکسِ چک‌لیستِ فردا ← `aria-label="آماده‌سازی زنگ ۳ — ریاضی"`.
- placeholder برچسب نیست؛ axe آن را نمی‌پذیرد.

## ۲) کنتراستِ رنگ (axe: color-contrast — serious)

متنِ عادی ≥ **4.5:1**، متنِ درشت (≥24px یا ≥18.7px bold) ≥ 3:1.

توکن‌هایِ AA-تأییدشده در `src/styles/base.css` (تغییرشان بدونِ اجرای تست ممنوع):

| توکن | مقدار | کاربرد | کنتراستِ سنجیده |
|---|---|---|---|
| `--green` | `#0a6f46` | متنِ سبز رویِ سفید و پس‌زمینهٔ toast.ok | 6.22 |
| `--red` | `#b7253f` | متنِ قرمز رویِ سفید و پس‌زمینهٔ toast.err | 6.27 |
| `--amber` | `#96590a` | متنِ کهربایی رویِ سفید، toast.warn | 5.63 |
| `--green-text` | `#0a6f46` | متن رویِ `--green-soft` (badge، sync-chip) | 5.61 |
| `--red-text` | `#b7253f` | متن رویِ `--red-soft` | 5.50 |
| `--amber-text` | `#96590a` | متن رویِ `--amber-soft` | 5.12 |
| `--muted` | `#556074` | متنِ کم‌اهمیت رویِ سفید/surface-2 | ≥6.0 |

قاعده‌ها:
- رنگِ متنِ رنگی رویِ پس‌زمینهٔ soft باید از توکنِ `-text` بیاید، نه توکنِ پایه.
- `opacity` زیرِ 0.9 رویِ متن ممنوع — کنتراستِ مؤثر را زیرِ آستانه می‌بَرد
  (تاریخ‌هایِ `class="small muted"` قربانیِ همین بودند).
- سرگروه‌هایِ سایدبار (`.nav-group`) باید رویِ **هر دو سرِ** گرادیانِ تیره ≥ 4.5 بدهند.
- تم‌هایِ ۲ و ۳ `--muted` خودشان را override می‌کنند — تغییرِ تم = اجرای دوبارهٔ تست.

## ۳) الگوهایِ موجودِ درست (دست نزنید)

- دکمه‌هایِ پوسته: `aria-pressed` + `title` دارند (`src/js/07-shell.js`).
- سگمنت/منویِ پوسته: `role="group"` / `role="menu"` + `aria-label`.
- بعدِ هر رندر، مودال‌ها با `closeModal()` بسته می‌شوند تا focus گیر نکند.

## ۴) چک‌لیستِ توسعه‌دهنده پیش از PR

```bash
node tests/a11y-regressions.js   # سریع، بدونِ مرورگر — همیشه
node tests/a11y-runtime.js       # اگر UI یا CSS دست خورده — نیازمندِ playwright
```

- کنترلِ فرمِ تازه ساختی؟ → برچسب بده و به §1 در `a11y-regressions.js` اضافه کن.
- رنگِ تازه تعریف کردی؟ → جفتِ متن/پس‌زمینه‌اش را به §2 اضافه کن.
- اسکنِ runtime نقضِ تازه گرفت؟ → رفع + کامیتِ جدا + چکِ رگرسیون، مطابقِ `docs/A11Y_RUNTIME_REPORT.md`.
