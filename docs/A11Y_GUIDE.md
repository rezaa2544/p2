# راهنمایِ دسترس‌پذیریِ توسعه‌دهنده (WCAG 2.1 AA)

این سند قراردادهایِ a11y پروژهٔ پایش است. هر تغییرِ UI باید این‌ها را
رعایت کند؛ رگرسیون در `tests/a11y-audit.js` (۴۰ بررسی) قفل شده است.

## ۱. قوانینِ سفت (P1 — شکستن = باگ)

1. **دکمهٔ آیکونیِ بی‌متن ممنوع:** هر `<button>` که فقط آیکون/✕ دارد
   باید `aria-label` فارسی داشته باشد (مثل `aria-label="بستن"`).
2. **فرم‌سازها:** ورودی‌ها فقط با `inp()`/`sel()` + `f()` ساخته شوند؛
   `f()` خودش `for` را از `id` استخراج می‌کند. `id` دستیِ بدونِ `for` نگذارید.
3. **مودال فقط با `openModal()`:** هرگز `.modal-back` را دستی در HTML
   نچینید (نمونه‌هایِ قدیمیِ `panelPicker`/`parentGate` استثناهایِ ثبت‌شده‌اند —
   به‌زودی به `openModal` مهاجرت می‌کنند). `openModal` خودشِ `role=dialog`،
   `aria-modal`، نامِ خودکار، انتقال/تله/بازگردانیِ فوکوس را می‌دهد.
4. **تصویر بدونِ `alt` ممنوع:** `alt` باید محتوایِ تصویر را بگوید، نه
   اسمِ فایل را. `canvas` تعاملی `role="img"` + `aria-label` می‌خواهد.
5. **جدولِ داده `thead` + `th scope="col"` می‌خواهد** (حتی جدول‌هایِ
   دوسِتونهٔ سنجه/مقدار). جدولِ چیدمانی نسازید.
6. **پیامِ کاربر فقط با `toast()`:** خودش `role="status"` می‌گذارد؛
   `alert()`/`innerHTML` برایِ پیام نزنید.
7. **اعداد/تاریخ:** نمایش فقط با `fa()`/`faD()`/`jalali()` (فارسی و شمسی)؛
   ذخیره همیشه ISO میلادی.
8. **رنگِ معنادار به‌تنهایی کافی نیست:** وضعیت‌ها badge متنی هم دارند؛
   کنتراستِ متنِ عادی ≥ 4.5 (جفت‌هایِ مجاز در `docs/A11Y_AUDIT.md` §۲).

## ۲. چک‌لیستِ هر PR لمسیِ UI

- [ ] `node tests/a11y-audit.js` سبز (۴۰/۴۰)
- [ ] جهش (mutation): یک `aria-label`/`alt`/`for` را بردارید → تست باید قرمز شود
- [ ] Tab تا تهِ صفحه: ترتیبِ فوکوس منطقی، تله نیست، فوکوس دیده می‌شود
- [ ] `node build.js --check` سبز (index.html + مُهرِ راهنما)

## ۳. الگوهایِ آماده

```js
// دکمهٔ آیکونی
`<button class="icon-btn" data-act="x-y" aria-label="بستن">✕</button>`
// فرم (for خودکار)
f('نام مدرسه *', inp('m_name', s.name))
// مودال (dialog + فوکوس خودکار)
openModal(modalTpl('ویرایش مدرسه', body, 'school-save'))
// پیام
toast('ذخیره شد', 'ok')
```

## ۴. بدهیِ ثبت‌شده (P2)

- کنتراستِ بج‌ها/تیترِ منو (تصمیمِ بصری می‌خواهد).
- `panelPicker`/`parentGate`: مهاجرت به `openModal`.
- `duty-del` (اسپنِ کلیک‌شدنیِ ۲۱): نیازمندِ `role` + نامِ صریح + فوکوس‌پذیری.
- حاشیه‌نویسیِ بومِ تکلیف فقط ماوس/لمس؛ ایموجی‌هایِ تزئینی `aria-hidden` ندارند.
