## ۲. کد نوشته‌شده vs تحلیل/سند

### ۲.۱ فایل/کد نوشته‌شده (هر سه push و با ls-remote تأیید)

* **`.claude/skills/payesh-standards/SKILL.md`** — قوانین ثابت پایش
  در یک فایل: قانون طلایی «تأیید کورکورانه نکن» + ۱۵ قانون اجباری:
  1. تست جهش اجباری برای هر آزمون مهم (بکاپ → جهش → بیلد → smoke →
     تأیید افت → بازگردانی → اجرای نهایی سبز)
  2. اجرای واقعی برای هر ادعا (jsdom، ایدیوم `W()`)
  3. `esc()` / `escAttr()` روی همهٔ ورودی کاربر
  4. تغییر داده فقط از راه journal (`applyOp`)
  5. token هرگز در فایل پروژه (فقط `~/.payesh_gh_token`)
  6. تاریخ ISO-گریگوری ذخیره، جلالی نمایش
  7. `index.html` دست‌نخورده (خروجی بیلد؛ `build.js --check` سبز)
  8. هر تغییر = کامیت جدا + push + تأیید `git ls-remote`
  9. مستندات در همان کامیت (AI_PROMPT/CONTRIBUTING/PROJECT_NOTES)
  10. HANDOFF بالای فایل در پایان هر سشن
  11. **بازبینی فساد اعداد فارسی با کد‌پوینت** بعد از هر نوشتار
  12. `New folder.rar` دست‌نخورده
  13. دادهٔ دمو فقط با `add()` (بازتولیدپذیر با SEED)
  14. بدون فریم‌ورک و وابستگی خارجی
  15. کنترل سمت کلاینت = مجوز واقعی نیست
  + چهار نقض شناخته‌شدهٔ دور ۲۸ (bcrypt، احراز سرور، دیتابیس
  واقعی، بررسی نقش سمت سرور) و دستورهای تست.
* **`.claude/skills/security-review-payesh/SKILL.md`** — بازبینی
  امنیتی **کلاینت‌ساید**:
  * اصل حاکم (الگوی Dilaz): **«بدون exploit کارکردن، یافته نداریم»**
    — exploit = آزمون jsdomِ اجراپذیر در smoke.js (همان فلسفهٔ
    تست جهش به شکل پروتکل)؛
  * چک‌لیست اجباری هفت‌ماده: نشت بین‌مدرسه‌ای (فیلتر school_id /
    کوئری‌های `visible*`؛ PoC با کاربر مدرسهٔ ۱ روی دادهٔ مدرسهٔ ۲)،
    `esc`/`escAttr` روی همهٔ ورودی (PoC با `<img onerror>`)، نبود
    token/رمز در فایل، یکپارچگی journal/applyOp، ورودی اکشن‌های
    تازه در 30-authz (بدون authz = P0)، مرز نقش روی نماها، ورودی
    journal مطابق تأیید UI؛
  * روش ۹ مرحله‌ای `security-expert` به‌عنوان مکمل؛
  * فهرست «نقض‌های شناخته‌شده و عمداً پذیرفته‌شده» دور ۲۸
    (مستقیماً از AI_PROMPT کپی — `TODO_BEFORE_PRODUCTION.md`) برای
    جلوگیری از هشدار کاذب؛
  * فرمت یافته: شدت P0–P3 + exploit اجباری + حلقهٔ بسته (آزمون
    exploit پس از فایکس سبز بماند).
* **هیچ کد اپلیکیشنی دست نخورد** — این دور فقط اسکیل/مستندات است.
