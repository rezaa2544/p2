## ۱.۳. نکات و یادداشت‌ها

### چالش‌ها

- **مرگِ git میانی (WAF):** ریپوی محلی بینِ دو پیام ریست شد و آبجکتِ کامیتِ tracing از بین رفت؛ همهٔ کارها از روی فایل‌های سالم بازسازی و دوباره کامیت/پوش شدند (هشِ نهاییِ tracing ‏`6aa99de` است).
- **jsdom روی node 20:** سید و تست‌ها روی node 20 کرش می‌کردند (`markAsUncloneable`)؛ همهٔ گیت‌ها با node ‏۲۲ اجرا شدند.
- **توکنِ ناکافی:** اولین توکن scope ‏`workflow` نداشت و پوشِ workflow رد شد؛ با توکنِ دوم کامل شد.

### تصمیم‌های معماری

- همه‌جا **fail-open برای ابزارِ کمکی** (tracing/WAF/rate-limit) تا افتِ ابزار = افتِ سرویس نشود؛ **fail-closed فقط برای تصمیمِ دسترسی** (authz).
- شمارندهٔ اتمیکِ Redis به‌جای GET+SET (حذفِ lost-update زیرِ burst).
- کدِ OTP/cooldown/تأخیرِ تصاعدی در فایل ماندند (تک‌مالکیتی)؛ فقط پنجره‌های شمارشی به Redis رفتند.

### انحراف‌ها از پرامپت اولیه

- **WAF:** پرامپت فقط پیکربندیِ nginx می‌خواست، ولی تستِ رفتار بدونِ تشخیصِ درون‌برنامه ناممکن بود؛ لایهٔ فقط-تشخیص اضافه شد (صفر اثر روی smoke).
- **Rate Limiting:** اسکچِ پرامپت as-is اجرا نشد (متدهای `incr/expire/ttl` نبودند؛ سقف‌ها فایل‌محور بودند) — مهاجرتِ واقعی انجام شد.
- **تنها تغییرِ رفتاری در هر ۴ کار:** سقفِ روزانهٔ OTP از «روزِ تقویمیِ UTC» به «۲۴ ساعتِ غلتان» (ثبت‌شده در دیزاین‌داک).
