## ۱) هدف و دامنه

**هدف:** ثبت ماندگار و قابل‌گزارش هر رخداد امنیتی برای روندها، درس‌ها و پاسخ‌گویی — نه جایگزین پست‌مورتم حادثه، بلکه نمای تجمیعی آن.

**دامنه (هر کدام باید اینجا ثبت شود):** حادثهٔ امنیتی (incident) · آسیب‌پذیری کشف‌شده (vulnerability) · افشای ناخواسته (exposure) · یافتهٔ ممیزی/بازبینی (audit finding) — صرف‌نظر از شدت، حتی اطلاعاتی.
