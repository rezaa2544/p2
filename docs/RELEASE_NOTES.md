#### ۷) مسیر ارتقا (از نسخهٔ تک‌سروری فعلی)

1. **پیش‌نیاز:** پشتیبان کامل از فروشگاه فعلی + بررسی ظرفیت (`docs/CAPACITY_MODEL.md`).
2. **مهاجرت داده:** اجرای ابزار رسمی تبدیل جی‌سان→دیتابیس (راهنما: `docs/MIGRATION_GUIDE.md` §۶) + راستی‌آزمایی شمارش/نمونه.
3. **زیرساخت:** بالاآوردن استک‌ها به ترتیب ران‌بوک (دیتابیس ← کش ← برنامه ← لبه).
4. **رصد:** استقرار استک رصدپذیری و تأیید اسکراپ (`docs/OBSERVABILITY_DEPLOYMENT.md`).
5. **بازگشت اضطراری:** ابزار بازسازی فروشگاه از دیتابیس + پشتیبان جی‌سان تا پایان پنجرهٔ پایداری.
6. **برش:** فعال‌سازی بوت دیتابیس-اول؛ پایش ۲۴ساعتهٔ نخست طبق بستهٔ انتشار.
