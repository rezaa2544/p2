# ماژولِ اموال/انبارِ مدرسه (E.5)

> ثبت/به‌روزرسانی/حذفِ تجهیزات + شمارها + تحویلدارِ تفویضی + جستجو.
> بنا شده روی ماژولِ موجود (`assets`) — بدونِ موازی‌کاری.

## ۱. داده

| کالکشن | فیلدهای کلیدی |
|---|---|
| `assets` | `school_id, name, category, status, location, note, total_count, usable_count, created_at` |
| `users.asset_staff` | پرچمِ تفویضیِ تحویلداری (`1` = تحویلدار) — فقط مدیر می‌دهد/پس‌می‌گیرد |

- وضعیت‌ها: `available / in_use / repair` (ENUM، ذخیره‌شده).
- شمارها: `۱ ≤ total` و `۰ ≤ usable ≤ total`؛ پیش‌فرضِ ثبت: `total=1` و usable خودکار
  (`available ← total`، بقیه ← ۰)؛ ردیف‌های قدیمِ بی‌شمار = تک‌قلم.
- دسته‌بندی همان متنِ آزادِ قبلی است (سازگاری با داده‌های فارسیِ موجود)؛
  نگاشت به enum انگلیسی در صورتِ نیاز، کارِ بعدی است.

## ۲. مجوزها

| عمل | مدیر | تحویلدار (دبیرِ `asset_staff=1`ِ هم‌مدرسه) |
|---|---|---|
| ثبت/حذفِ تجهیز | ✅ | ❌ |
| به‌روزرسانی (وضعیت/مکان/شمار) | ✅ | ✅ |
| جستجو + مشاهده | ✅ | ✅ |
| اعطا/لغوِ تحویلداری | ✅ | ❌ |

لایه‌ها: گاردِ مسیر (`canRoute` + منوی تزریقی) ← گاردِ کلیک (`ACTION_ROLES`) ←
گاردِ داده (`assetStaffCan`) ← سرور (`model.json` + `inScope` + `STATUS_UPD_ROLE`).
تحویلدار در سطحِ **مدرسه** عمل می‌کند (نه کلاس). روزِ غیرحضوری، `in_use` همچنان
مسدود است (کلاینت + آینهٔ سرور، بدونِ تغییر).
