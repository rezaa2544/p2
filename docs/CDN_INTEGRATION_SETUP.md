# راه‌اندازیِ اتصالِ CDN (ویو ۱۲)

**وضعیت:** سندِ مرجع برایِ استقرارِ ملی — پیش‌فرض: **Cloudflare** (سطحِ رایگان کافی است)
**فلسفه:** ارزشِ CDN برایِ پایش = جذبِ DDoS + خاتمهٔ TLS + لبهٔ امنیتی، نه کشِ محتوا.

---

## ۱) چرا کشِ لبه برایِ پایش «خاموش» است؟

۱. **ننسِ یک‌بارمصرفِ CSP:** هر پاسخِ HTML شاملِ ننسِ تصادفیِ همان درخواست است
   (`__PAYESH_NONCE__` در `build.js` → جایگزینی در `serveStatic`). اگر لبه
   صفحه‌ای را کش کند، یک ننس بینِ همهٔ کاربرها مشترک می‌شود ⇒ هم‌زمان:
   - تضعیفِ واقعیِ CSP (مهاجم می‌تواند با ننسِ لو رفته اسکریپت تزریق کند)،
   - و شکستنِ رندر برایِ درخواست‌های بعدی در برخی مرورگرها.
۲. **حجمِ کم:** کلِ فرانت یک فایلِ `index.html` است (بدونِ داراییِ جدا)؛
   صرفه‌جوییِ پهنای‌باندِ کش نزدیکِ صفر است و ارزشی ندارد که ریسکِ بالا را بپذیریم.
۳. **API هرگز کش نمی‌شود:** همهٔ پاسخ‌هایِ `/api/*` از سرور `Cache-Control: no-store`
   می‌گیرند و داده‌شان نشست‌محور است.

نتیجه: در لبه **Bypass Cache روی همهٔ مسیرها**. هر گاهی که کسی پیشنهادِ
«کش کنیم سریع‌تر شود» داد، اول بندِ ۱ را بخواند.

## ۲) چک‌لیستِ پیکربندیِ Cloudflare

| بخش | تنظیم | دلیل |
|---|---|---|
| DNS | رکوردِ دامنه = **ابرِ نارنجی** (proxied) | عبور از لبه؛ مخفی‌ماندنِ IP اوریجین |
| SSL/TLS | حالتِ **Full (strict)** + حداقل TLS 1.2 + Always Use HTTPS | رمزنگاریِ سرتاسری؛ گواهِ اوریجین باید معتبر باشد (بندِ ۴) |
| Cache Rules | یک قانون: `*` → **Bypass cache** | بندِ ۱ — ننسِ CSP و دادهٔ نشست‌محور |
| Speed | Brotli/gzip روشن، HTTP/2 و HTTP/3 روشن | فشرده‌سازی بدونِ تغییرِ بدنه |
| Speed | **Rocket Loader خاموش**، Auto Minify رویِ HTML خاموش | بازنویسیِ اسکریپت/تماس با ننسِ CSP ناسازگار است |
| Security | Managed Ruleset (OWASP + Cloudflare Managed) + قانونِ نرخِ ۱۰۰r/m روی `/api/*` | هم‌راستا با `docs/WAF_DDOS_SETUP.md` §۱.۲ |
| Security | Bot Fight Mode روشن (با استثنا برایِ سلامت‌سنجی‌ها) | کاهشِ ربات |
| HSTS | فعال در Cloudflare یا از خودِ برنامه (برنامه وقتی پشتِ پروکسیِ `PAYESH_HTTPS=1` است HSTS می‌فرستد) | `max-age=31536000; includeSubDomains` |
| Cache Reserve | خاموش | کشی وجود ندارد که ذخیره شود |
| Analytics | روشن (نظارتِ ترافیک/تهدید) | ورودیِ چک‌لیستِ عملیاتی |

## ۳) سرآیندها و متغیرهایِ اوریجین

| سرآیند/متغیر | مقدار در اوریجین |
|---|---|
| `X-Real-IP` / `X-Forwarded-For` | توسطِ `nginx/nginx.conf` تنظیم می‌شود (لبهٔ دوم) |
| `PAYESH_HTTPS=1` | هنگامِ استقرار پشتِ لبه حتماً تنظیم شود (تشخیصِ `isHttps` → HSTS و کوکیِ Secure) |
| `PAYESH_BEHIND_PROXY=1` | برایِ بوتِ بدونِ گواهِ محلی در پروداکشن (فقط پشتِ لبهٔ معتبر) |
| سرآیندهایِ امنیتی (CSP, X-Frame-Options, …) | فقط از اوریجین؛ در لبه سرآیندِ امنیتیِ اضافه **نسازید** (تعارض با ننس) |

## ۴) گواهی و زنجیرهٔ اعتماد

- گواهِ اوریجین باید **صادرشده از CA** باشد (حالتِ Full (strict) آن را می‌خواهد؛
  سرور هم در پروداکشن گواهِ خودامضا را رد می‌کند — `server/index.js`، پیامِ
  «Production requires valid CA certificate»).
- مسیرِ پیشنهادی: گواهیِ لبه = Universal SSL خودِ Cloudflare؛ گواهِ اوریجین =
  Origin CA (فقط اگر اوریجین مستقیم در معرض نیست) یا Let's Encrypt/certbot.

## ۵) قفل‌کردنِ اوریجین (جلوگیری از دورزدنِ لبه)

فایروالِ سرور فقط پورت‌هایِ ۸۰/۴۴۳ را از **بازهٔ IPهای رسمیِ لبه** بپذیرد
(فهرست‌هایِ `https://www.cloudflare.com/ips/` + cronِ به‌روزرسانی). جزئیات در
`docs/WAF_DDOS_SETUP.md` §۱.۳. بدونِ این بند، مهاجم با کشفِ IP اوریجین کلِ
لبه را دور می‌زند.

## ۶) روالِ استقرار و پاک‌سازی

1. استقرارِ نسخهٔ تازه (فقط فایل‌هایِ اوریجین تغییر می‌کنند).
2. چون کشی نداریم، **نیاز به purge نیست** — اگر روزی داراییِ کش‌شونده اضافه شد
   (مثلاً تصاویرِ راهنما)، هم‌زمان قانونِ کش و روالِ `Purge by hostname` در
   همین سند ثبت شود.
3. بررسیِ پس از استقرار: `/api/health` از بیرون = ۲۰۰، سرآیندهایِ امنیتیِ پاسخِ
   `/` دست‌نخورده (مقایسه با خروجیِ مستقیمِ اوریجین).

## ۷) آزمون‌ها و ممیزیِ خودکار

- `tests/wave12-network.js` — گروه‌هایِ:
  - `HDR`: سرآیندهایِ امنیتیِ زنده (شاملِ حضورِ HSTS پشتِ `PAYESH_HTTPS=1`
    و نبودنش در `http` ساده، ننسِ یکتا در هر درخواست)،
  - `EDGE`: استخراجِ رگکس‌هایِ لبه از `nginx.conf` و تستِ مثبت/منفی،
  - `CIN`: حضورِ گام‌هایِ SAST/SCA در `security.yml`،
  - `DOC`: همین سند و بخش‌هایِ الزامی‌اش.
- `tests/waf-ddos.js` — نرخ/ربات/تراورسال (پیش از ویو ۱۲).
