## ۲. آنچه واقعاً کد شد (نه برنامه)

### بند ۱۱ — سرویس ۲: امنیت (`48-bus-service.js`)
- **R1 — پاسخ اولیا:** جدول `bus_needs{route_id,student_id,answer,updated_at,
  updated_by}` (upsert بر پایهٔ دانش‌آموز؛ سه حالت: «لازم ندارد» /
  «خودم تهیه می‌کنم» / «بر عهدهٔ مدرسه»). ولی از تبِ تازهٔ «🚌 سرویس» در
  پروندهٔ فرزندش پاسخ می‌دهد — **فقط فرزندش** (روی داده از `parent_links` +
  `S.child`؛ ولیِ چندفرزند با سوییچر). مدیر از کارت «پاسخ اولیا» در پنل
  سرویس ثبت/ویرایش می‌کند (شمارندهٔ بدون‌پاسخ + بجِ هر دانش‌آموز).
- **R2 — ثبت دوسویه + مشکوک:** دانش‌آموز از همان تب «من سوار شدم / من
  پیاده شدم» می‌زند (`source:'student'`؛ فقط رویدادِ خودش روی مسیرِ خودش).
  `busMismatch(studentId, date)` محاسبه‌شده (ذخیره نمی‌شود): `none` /
  `pending` (فقط یک طرف ثبت کرده) / `ok` / `conflict` (هر دو ثبت کرده و
  ساعت‌ها مغایرت دارند) — مغایرت با ⚠️ در پنل مدیر، راننده و ولی نشان
  می‌خورد.
- **R3 — موقعیت:** `bus_locations{route_id,student_id(0=خودرو),source,pos,
  lat,lng,recorded_at}` — راننده/دانش‌آموز «موقعیت بفرست» می‌زنند؛ `pos` =
  درصد روی مسیر (۰ تا ۱۰۰)؛ ولی شماتیکِ مسیر + آخرین نقطهٔ هر طرف را
  می‌بیند. `lat`/`lng` رزرو و خالی‌اند (جی‌پی‌اس واقعی → قفل ۱۱.۱).
- تب «🚌 سرویس» در پروندهٔ دانش‌آموز (ولی فقط‌خوان) + ۶ اکشن/مجوز تازه +
  دادهٔ نمونهٔ کامل (مسیر، دانش‌آموزان، رویدادها، پاسخ‌ها، موقعیت‌ها).

### بند ۱۲ — کلاس مجازی ۲ + تکالیف ۲
**حضورِ خودکار (`50-vclass.js`):**
- جدول `vclass_attendance{session_id,student_id,joined_at,left_at,by}` — یک
  ردیف برای هر (نشست، دانش‌آموز). `vclassJoin` (ورود = `joined_at` ISO) +
  `vclassLeave` (خروج = `left_at`؛ بازموردن = همان ردیف، joined تازه).
  «حالا داخل کلاس» = joined دارد و left خالی است (`vclassPresentNow`).
- **روی داده، نه فقط دکمه:** فقط خودِ دانش‌آموز (ولی/دبیر رد) + فقط نشستِ
  کلاسِ خودش؛ ورودِ تکراری رد؛ خروجِ بدون ورود/تکراری رد.
- نمایش: تب کلاس مجازیِ پرونده — دانش‌آموز دکمهٔ ورود/خروج دارد
  (`vc-join`/`vc-leave` + برچسبِ زندهٔ «🟢 الان داخل / ✅ شرکت‌کرد / هنوز
  وارد نشده»)، ولی فقط‌خوان؛ پنل دبیر شمارندهٔ «الان: N» + بجِ شرکتِ هر
  دانش‌آموز. دادهٔ نمونه: یکی الان داخل + یکی شرکت‌کرده و خارج.

**تکالیف — رسانه/تایمر/قفل (`51-homework.js`):**
- **رسانه:** `accept` فرم = تصویر + صوت + ویدیو + PDF/Office (ستون‌های
  `file_name`/`mime`/`size` از قبل بودند — همان قفل ۴.۱). مودال «مشاهده»
  (`hwViewModal`) بر اساس `mime` پخش می‌کند: `<img>` / `<audio>` / `<video>` /
  بقیه = نام + حجم + دانلود. دانش‌آموز دکمهٔ مشاهدهٔ بارگذاریِ **خودش** را
  دارد؛ guard در خودِ تابع (دانش‌آموزِ دیگر → هیچ).
- **قفل/تایمر (دستِ دبیر):** فیلدهای تازهٔ `hw_assignments`: `locked` (قفلِ
  دستی — دکمهٔ 🔒/🔓 روی کارتِ دبیر؛ **همیشه روی تایمر مقدم**) +
  `window_open`/`window_close` (datetime-local، دقتِ دقیقه — «فضا ساعت ۸ تا
  ۹ باز است»). `hwIsOpen` → `open`/`locked`/`before`/`after` (تکلیفِ بدون
  فیلد = باز). `hwSubmit` وقتی بسته، با پیامِ مشخص رد می‌کند (روی داده).
  `hwSetWindow` (دبیرِ کلاس/مدیر/سوپرادمین؛ اعتبارسنجی: ساعت معتبر + پایان
  بعد از شروع). فرمِ دانش‌آموز وقتی بسته غیرفعال می‌شود + بجِ وضعیت
  (`hwWindowBadge`) روی هر دو صفحه. دادهٔ نمونه: ۳ تکلیف (بازه‌دار + صوتی
  باز + قفل‌شدهٔ نمونه).
- **اصلاحِ پنهان در دمو:** `window_open` نمونه از `now.slice(0,13)` به
  `now.slice(0,11)` — رشتهٔ ساعتِ نامعتبر (مثل `2026-09-05T1208:00`) را
  برطرف کرد.
- ۵ اکشن/مجوز تازه: `vc-join`/`vc-leave` [دانش‌آموز] · `hw-window`/
  `hw-window-save`/`hw-lock` [دبیر،مدیر،سوپرادمین] · `hw-view` [دبیر،مدیر،
  دانش‌آموز،سوپرادمین].

### بند ۱۳ — حالت حضوری/غیرحضوری مدرسه (`57-school-mode.js` — ماژولِ تازه)
- جدول `attendance_modes{school_id,date,mode:'in_person'|'virtual',set_by,
  set_at}` (جدول از قبل رزرو‌شده بود) — کلید (مدرسه، روز)، upsert؛ **بدون
  ردیف = حضوری** (پیش‌فرض).
- `setSchoolMode` — مالکیت روی داده: سوپرادمین همه؛ **مدیر فقط مدرسهٔ
  خودش**؛ **edu_office فقط مدرسه‌های داخل scope ادارهٔ خودش**
  (`officeScopeSchools(officeOf(u))` — استان/شهرستان/منطقه). اعتبارسنجی
  تاریخ ISO + حالت.
- **«خودکار مجازی‌شدنِ کلاس/فضا/تجهیزات» در این نسخه = سطحِ نمایش**
  (قفل ۱۳.۱): `virtualModeBanner` فقط برای کارکنانِ همان مدرسه (مدیر/دبیر/
  مشاور/راننده — نه دانش‌آموز) در ۶ نما: حضور (با تاریخِ انتخابی)،
  کلاس‌ها، کلاس مجازی، کتابخانه، مهمان‌ها، املاک. داشبوردِ مدیر: کارت
  «حالت مدرسه امروز» + دکمهٔ toggle سریع (`smode-mgr`). فهرست مدارسِ اداره:
  بجِ حالت (🏫 حضوری / 🏠 غیرحضوری) + دکمهٔ «حالت» → مودالِ تاریخ+حالت
  (`smode-open`/`smode-save`).
- دمو: دومین مدرسهٔ فعال «امروز» غیرحضوری است (بج و نوار در دمو دیده می‌شود؛
  مدرسهٔ اول حضوری می‌ماند تا جریانِ عادیِ دمو دست‌نخورده بماند) — از مولدِ
  قطعی + مسیرِ restoreBackup (دو جا).

6. **غیرحضوری (R5):** «خودکار مجازی‌شدن» فعلاً سطحِ نمایش است (نوار/بج/

ثبت‌شده در بخشِ برترِ «اصلِ واقعیت» در
