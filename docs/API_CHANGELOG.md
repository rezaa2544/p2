## ۸) نسخهٔ پروتکل همگام‌سازی (A01)

| جزء | نسخه/وضعیت | مرجع |
|---|---|---|
| **پول (pull)** | دلتای پی‌جی-بنیاد از ویو ۱ (موج ۱)؛ فال‌بک شفاف به واکشی کامل وقتی پی‌جی خاموش | `docs/SYNC_PROTOCOL.md` §۲ |
| **کرسر (cursor)** | صفحه‌بندی پایدار با `lastUpdatedAt + lastId` در `deltaRowsSql` | `server/dbquery.js` |
| **سنگ‌قبر (tombstone)** | حذف نرم در `__deleted_records` + جدول آمادهٔ `server_tombstones`؛ پول دلتا سنگ‌قبرها را می‌فرستد | `docs/SYNC_PROTOCOL.md` §۲ · `tests/tombstone.js` (۲۵/۲۵) |
| **پوش (push)** | موتور امنیتی تک‌فاز فعلی؛ **بازنویسی در یک تراکنش پی‌جی هنوز باقی است** (قید صریح §۲ پروتکل + مانع پ0-۱) | `server/sync.js` |
| تعارض | ثبت + حل با او‌سی‌سی `base_version` | `tests/occ.js` (۱۸/۱۸) |

**تغییرات ای۰۱ از آغاز:** هر ارتقای جزء بالا یک ردیف می‌گیرد؛ نسخهٔ پروتکل با تغییر قرارداد پاسخ پول تغییر می‌کند (نه با تغییرات داخلی).
