## سیاست انتقال

- فایل‌های Root که کد/تنظیمات/entrypoint نیستند و ماهیت گزارش، audit، handoff، baseline یا تصمیم تاریخی دارند در اینجا دسته‌بندی می‌شوند.
- فایل‌های Root عملیاتی و ورودی پروژه مانند `README.md`، `AGENTS.md`، `CLAUDE.md`، `CONTRIBUTING.md` و `SECURITY.md` در Root باقی می‌مانند.
- حذف فقط برای فایل‌هایی انجام می‌شود که پس از Reference Audit مشخصاً زائد، قدیمی و فاقد ارزش provenance باشند.
- هر گزارش تاریخی ممکن است به مسیرهای تاریخی قدیمی اشاره کند؛ این ارجاعات نباید به‌عنوان وضعیت جاری تفسیر شوند.
