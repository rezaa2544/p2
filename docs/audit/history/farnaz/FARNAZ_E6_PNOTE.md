# گزارش E.6 فرناز — یادداشت شخصی ولی (چت ۳، آیتم ۶ — پایان دستهٔ E)

## چه ساخته شد (کاملاً کلاینت، بدون سرور)
- کارت «📝 یادداشت شخصی من» بالای پروفایل هر فرزند در نمای ولی (`viewChildren`): جعبهٔ متن
  (سقف ۵۰۰ نویسه) + دکمهٔ «💾 ذخیره یادداشت» + تاریخ «آخرین به‌روزرسانی»؛ اگر خالی: «هنوز یادداشتی ثبت نشده».
- ذخیره فقط در `Store` با کلید `payesh_note_<parentId>_<studentId>` (JSON شامل متن + تاریخ)؛
  ذخیرهٔ خالی = پاک‌سازی یادداشت.

## حریم خصوصی (سه‌لایه)
1. **کلید:** شناسهٔ خودِ ولی در کلید است — والد دیگر یادداشت جداگانهٔ خودش را دارد.
2. **رندر:** کارت فقط برای ولیِ لینک‌شده به همان فرزند رندر می‌شود (دانش‌آموز/مدیر/ولیِ نامرتبط = رشتهٔ خالی).
3. **اکشن:** `pnote-save` هم نقش (`canAction: parent`) هم لینک‌بودن را چک می‌کند؛ ۵۰۱+ نویسه رد می‌شود؛
   خروجی با `esc` گریز می‌خورد (تست XSS سبز).
