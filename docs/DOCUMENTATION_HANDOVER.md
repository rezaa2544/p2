## ۴) نسخهٔ برون‌خطی (اچ‌تی‌ام‌ال/پی‌دی‌اف)

این سند و کل کتابخانه مارک‌داون‌اند؛ برای آفلاین یا ارائه:

```bash
# پی‌دی‌اف یک سند (راست‌به‌چپ با فونت وزیرمتن/ایران‌سنس):
pandoc docs/GO_LIVE_PACKAGE.md -o payesh-go-live.pdf --pdf-engine=xelatex \
  -V lang=fa -V dir=rtl -V mainfont="Vazirmatn"

# اچ‌تی‌ام‌ال خودکفا برای مرور بدون ریپو:
pandoc docs/DOCUMENTATION_HANDOVER.md -s --metadata title="بستهٔ تحویل مستندات پایش" \
  --css=style.css -o handover.html
```

> **وضعیت فعلی (صداقت):** پنداک در این سندباکس نصب نیست؛ اسکریپت `tools/docs-export.sh`
> ساخته شده و بدون پنداک با کد ۰ و پیام خارج می‌شود (راهنمای نصب و اجرا:
> `docs/DOCS_EXPORT_GUIDE.md`). تبدیل واقعی در محیط دارای پنداک/زلاتکس اجرا می‌شود.
