## ۴. 🔴 یافتهٔ تازهٔ این بازبینی — نشتِ دامنه در خروجیِ ICS

بازبینیِ Devin این را **ندیده بود**. با پروبِ زندهٔ jsdom کشف و اثبات شد.

### ۴.۱ ریشه

دکمه با `data-sid` ساخته می‌شود:

```html
<button data-act="ics-export" data-sid="1021">📥 تقویم (ICS)</button>
```

اما دیسپچرِ سراسری در `19-actions-core.js` فقط `data-id` را می‌خواند:

```js
const a = el.dataset.act, rawId = el.dataset.id;   // ← data-sid خوانده نمی‌شود
```

پس در استفادهٔ عادی `id` همیشه `undefined` است و کد به شاخهٔ امن می‌افتد:

```js
'ics-export'(el, id){
  var sid = id ? Number(id) : recordTargetId();   // ← فقط این شاخه گارد دارد
  if(sid) icsDownload(sid);
}
```

`recordTargetId()` گاردِ درستی دارد (ولی را به `parent_links` محدود می‌کند).
**ولی شاخهٔ `id` هیچ گاردی ندارد** — و مهاجم می‌تواند آن را فعال کند.

### ۴.۲ اثباتِ زنده (اجرا شد، حدس نیست)

مهاجم = ولیِ واقعیِ سامانه (شناسه ۲، مدرسهٔ ۶). در کنسول:

```js
var b = document.createElement('button');
b.setAttribute('data-act','ics-export');
b.setAttribute('data-id','16');       // ← دانش‌آموزِ بیگانه، مدرسهٔ ۱
document.body.appendChild(b); b.click();
```

نتیجهٔ واقعی:

```
canAction("ics-export") برای ولی → true      (اکشنِ بی‌برچسب)
پس از کلیک: Blob ساخته شد؟ → yes
ICSِ بیگانه: ۱۲۷۴ بایت، دارای رویداد
ICSِ فرزندِ خودم: ۸۵ بایت (خالی)
نشت: SUMMARY:امتحان دین و زندگی ۱ 08:00 | امتحان فارسی ۱ 10:30 | ...
```

فایلِ دانش‌آموزِ **مدرسهٔ دیگر** دانلود شد.

### ۴.۳ شدت — با انصاف

| سنجه | ارزیابی |
|---|---|
| چه چیزی نشت می‌کند | نامِ درس، تاریخ/ساعتِ امتحان، نامِ سالن، عنوانِ رویدادهای مدرسه |
| PII دارد؟ | ❌ **نه** — بدونِ نام، تلفن، کد ملی (با اجرا تأیید شد) |
| مرزِ مدرسه را می‌شکند؟ | ✅ **بله** — مدرسهٔ ۶ دادهٔ مدرسهٔ ۱ را گرفت |
| نیازمندِ چیست | حسابِ معتبر + دستکاریِ دستیِ DOM |
| در حالتِ سرور | همچنان کار می‌کند — **این خواندنِ حافظهٔ محلی است، نه درخواستِ شبکه**، پس `idor.js` جلویش را نمی‌گیرد |
| هم‌ردهٔ بدهیِ شناخته‌شده؟ | بله — از خانوادهٔ «IDOR در `04-queries.js byId`» در §۰.۵.۵ |

**ارزیابیِ صادقانه: متوسط، نه بحرانی.** برنامهٔ امتحاناتِ یک کلاس رازِ درجه‌یک
نیست و PII ندارد. اما **اصلِ نهمِ پروژه** («هر داده‌ای که نقش اجازهٔ دیدنش را
ندارد نباید به مرورگر برسد») را نقض می‌کند و مرزِ مدرسه را می‌شکند.

### ۴.۴ رفع — ✅ **انجام شد** (به دستورِ صریحِ ناظر: «بررسی و رفع کن»)

```js
'ics-export'(){
  var sid = (typeof recordTargetId==='function') ? recordTargetId() : null;
  if(sid) icsDownload(sid);
}
```

ورودیِ `id` عمداً حذف شد و `data-sid` هم از دکمه برداشته شد.
