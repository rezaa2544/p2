# 🏫 راهنمای جامع و دسته‌بندی‌شده کادر مدرسه، معلمان، اولیا و دانش‌آموزان

این پوشه شامل راهنماهای تفکیک‌شده موضوعی (آموزشی، انضباطی، اجرایی، ارتباطی) و آموزش‌های فصل‌به‌فصل برای تمامی ارکان مدرسه در سامانه «پایش» است.

---

## 📑 فهرست راهنماهای موضوعی این بخش:

1. **[`راهنمای_جامع_بخش_آموزشی.md`](راهنمای_جامع_بخش_آموزشی.md)**  
   برنامه هفتگی درسی، زنگ هوشمند، ثبت نمرات مستمر و پایانی، امتحانات نهایی، تکالیف دیجیتال با تصحیح روی Canvas، صدور کارنامه و کلاس مجازی.

2. **[`راهنمای_جامع_بخش_انضباطی_و_پرورشی.md`](راهنمای_جامع_بخش_انضباطی_و_پرورشی.md)**  
   ثبت حضور و غیاب صفر-کلیک، تاخیرها، مرخصی‌های آنلاین، سیستم امتیاز و گیمیفیکیشن دبستان (Dojo)، صف مشاوره و الگوهای پیشگیری از افت تحصیلی.

3. **[`راهنمای_جامع_مدیریت_و_اجرایی.md`](راهنمای_جامع_مدیریت_و_اجرایی.md)**  
   مدیریت چرخه سال تحصیلی، چیدمان متوازن کلاس‌ها، ویزارد ۴ مرحله‌ای اکسل سیدا، مدیریت خوابگاه شبانه‌روزی، سرویس مدرسه، اموال، کتابخانه و دفتر مراجعین.

4. **[`راهنمای_ارتباطات_و_اطلاع_رسانی.md`](راهنمای_ارتباطات_و_اطلاع_رسانی.md)**  
   تابلو اعلانات، پیام‌رسان داخلی، صف پیامک هوشمند با پنجره مهلت لغو، سامانه رزرو جلسات اولیا و مربیان و صورتجلسات انجمن اولیا.

5. **[`راهنمای_اختصاصی_نقش_ها_فصل_به_فصل.md`](راهنمای_اختصاصی_نقش_ها_فصل_به_فصل.md)**  
   فصل‌های آموزشی تفکیک‌شده و گام‌به‌گام برای: مدیر مدرسه، معاون اجرایی/آموزشی، معلم، مشاور، راننده سرویس، سرپرست خوابگاه، دانش‌آموز و اولیا (با سوییچر چندفرزندی).

6. **[`راهنمای_تصویری_تعاملی_مدرسه.html`](راهنمای_تصویری_تعاملی_مدرسه.html)**  
   پورتال چندرسانه‌ای و تعاملی مدرسه با کارت‌های بصری و دسترسی بدون محدودیت به تمام منوها (بدون هرگونه مودال یا پیام مزاحم).
