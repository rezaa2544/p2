# 🛠️ راهنمای جامع سازنده، مالک محصول و پشتیبان ارشد سامانه «پایش»

این پوشه حاوی کلیه مستندات عملیاتی، دستورالعمل‌های رفع عیب (Troubleshooting)، پایگاه دانش پشتیبانی سریع و ابزارهای مانیتورینگ برای سازنده سامانه است.

---

## 📑 فهرست مستندات این بخش:

1. **[`راهنمای_جامع_سازنده_و_پشتیبان_ارشد.md`](راهنمای_جامع_سازنده_و_پشتیبان_ارشد.md)**  
   شرح کامل معماری زیربنایی، نحوه کارکرد موتور دیاگ خودکار ۲۹ مرحله‌ای (`42-self-diagnostics.js`)، بازیابی امن دیتابیس و مدیریت بحران.

2. **[`دستورالعمل_حل_مشکلات_و_پاسخ_به_کاربران.md`](دستورالعمل_حل_مشکلات_و_پاسخ_به_کاربران.md)**  
   پایگاه دانش جامع (Knowledge Base) پاسخ‌گویی به تیکت‌ها و تماس‌های کاربران (مدیران، معلمان، اولیا و دانش‌آموزان) با سناریوهای حل فوری در کمتر از ۲ دقیقه.

3. **[`راهنمای_عملیاتی_سوپرادمین_و_سرور.md`](راهنمای_عملیاتی_سوپرادمین_و_سرور.md)**  
   راهنمای مانیتورینگ عقربه‌های سلامت سرور، قابلیت جانشینی مدیر (`S.boss`) برای عیب‌یابی بدون رمز عبور، تنظیم قابلیت‌های مدارس (`Capabilities`) و مدیریت تعرفه‌ها.

4. **[`داشبورد_تصویری_پشتیبانی_و_دیاگ.html`](داشبورد_تصویری_پشتیبانی_و_دیاگ.html)**  
   پنل تصویری و تعاملی پشتیبانی و دیاگ آنلاین، راهنمای خطایابی سریع و قالب‌های آماده پیام پشتیبانی (بدون هرگونه پاپ‌آپ یا اعلان مزاحم).
