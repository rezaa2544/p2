## قواعد نگهداری
1. منبع اصلی مستندات فنی و حاکمیتی = `docs/`.
2. `reza/` فقط محتوای مخاطب‌محور اختصاصی را نگه می‌دارد.
3. از کپی بیت‌به‌بیت یک سند در چند مسیر خودداری می‌شود.
4. ادعای VERIFIED/COMPLETED باید به SHA/CI/شاهد قابل بازاجرا متصل باشد.
5. گزارش تاریخی حذف نمی‌شود؛ در کاتالوگ گزارش‌ها طبقه‌بندی می‌شود.
