# 💻 راهنمای اختصاصی تیم فنی و برنامه‌نویسی سامانه «پایش»

این پوشه حاوی کلیه مستندات فنی، معماری مهندسی نرم‌افزار، راهنماهای توسعه کد، پروتکل‌های امنیتی و فایل‌های آزمون خودکار سامانه پایش است.

---

## 📑 فهرست مستندات فنی موجود در این بخش:

1. **[`معماری_و_مستندات_فنی.md`](معماری_و_مستندات_فنی.md)**  
   تشریح کامل معماری کلاینت-محور، لایه انتزاع داده (`00-data-layer.js`)، پایگاه‌داده محلی (`IndexedDB` با ۳ استور اختصاصی)، موتور همگام‌سازی دوطرفه (`A01 Pull & Push Sync`)، سیستم ایندکس‌گذاری حافظه و مدیریت نشست‌ها.

2. **[`راهنمای_کدنویسی_و_توسعه_ماژول‌ها.md`](راهنمای_کدنویسی_و_توسعه_ماژول‌ها.md)**  
   استانداردهای توسعه ماژول جدید (Vanilla JS مستقل)، قوانین عدم وابستگی خارجی، ساختار فایل `_order.json`، نحوه اتصال به اکشن‌باس (`19-actions-*.js`) و اجرای فرآیند کامپایل (`node build.js`).

3. **[`مستند_امنیت_و_مجوزها.md`](مستند_امنیت_و_مجوزها.md)**  
   ماتریس کنترل دسترسی مبتنی بر نقش (`RBAC`) برای ۷ نقش کاربری، اعتبارسنجی ۳۳۷ اکشن سیستمی، گارد کلاینت/سرور (`tools/check-authz.js`)، راهکارهای پیشگیری از حملات XSS و تزریق فرمول‌های CSV.

4. **[`گزارش_پیاده_سازی_موتور_سینک_A01.md`](گزارش_پیاده_سازی_موتور_سینک_A01.md)**  
   گزارش جامع پیاده‌سازی موتور کشش داده‌ها (`A01 Universal Pull`)، دلتاهای تغییرات زمانی (`since timestamp`) و مدیریت رکوردهای حذف‌شده (`Tombstones`).

5. **[`راهنمای_تصویری_معماری_سیستم.html`](راهنمای_تصویری_معماری_سیستم.html)**  
   داشبورد تعاملی و بصری معماری نرم‌افزار شامل دیاگرام‌های گرافیکی جریان داده، ساختار IndexedDB و نقشه ماژول‌ها بدون هیچ‌گونه اعلان یا مانع بصری.

6. **[`index.html`](index.html)**  
   نسخه نهایی کامپایل‌شده اپلیکیشن تک‌فایلی جهت تست و بازبینی عملکردی.

---

## 🚀 دستورات پرکاربرد توسعه‌دهندگان:

```bash
# کامپایل مجدد برنامه و ساخت index.html و dist/payesh.html
node build.js

# اجرای سوئیت کامل تست‌های خودکار (تست ساختار، تست دودی ۵۴۷ مرحله‌ای، ایندکس‌دی‌بی، سینک A01 و امنیت)
node tests/run.js && node tests/smoke.js && node tools/check-authz.js && node tests/idb-persistence.js && node tests/pull-bootstrap.js
```
