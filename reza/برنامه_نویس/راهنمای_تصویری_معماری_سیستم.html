۱. استور entities (رکوردهای داده)

ایندکس‌ها: by_collection, by_school, by_updated

await offlineStorage.putEntity('grades', { id: 'g_102', school_id: 1, student_id: 'std_55', score: 19.5, version: 2 });
۲. استور sync_queue (صف ارسال آفلاین)

کلید اصلی: id (auto-increment)

ایندکس‌ها: by_status, by_created_at, by_attempts

await offlineStorage.addToQueue({ action: 'grade-save', payload: { id: 'g_102', score: 19.5 }, base_version: 1, status: 'pending' });
