## ۵. CI — چه چیزی خودکار بسته می‌شود (پس از اصلاحاتِ این دور)

**ریشهٔ خرابیِ سه‌روزه (از ران ۴۸):** `security.yml` به `zaproxy/actions-baseline@v0.12.0`
اشاره داشت — آن مخزن **وجود ندارد** (اکشنِ واقعی: `zaproxy/action-baseline`). گیت‌هاب
همهٔ `uses:`ها را در استارتاپ resolve می‌کند؛ اکشنِ ناموجود ⇒ شکستِ کلِ ران با **صفر job**
(همان علامتی که از ران ۴۸ به بعد دیدیم). اصلاحاتِ این دور:

| فایل | اصلاح | اثر |
|---|---|---|
| `.github/workflows/security.yml` | `actions-baseline` ← `action-baseline` | رانِ Security Program (SAST/Secret/SCA/SBOM/DAST/WAF) دوباره بالا می‌آید |
| `.github/workflows/node.js.yml` | ماتریس `[18.x,20.x,22.x]` ← `[22.x]` | حذفِ لِین‌های سبزِ کاذب (jsdom 30 روی 18/20 اصلاً require نمی‌شود و smoke با exit 0 رد می‌شد) — هم‌تراز با `engines: >=22` |
| `.github/workflows/npm-publish-github-packages.yml` | `node-version: 20` ← `22` (هر دو job) | انتشار روی همان نسخه‌ای که واقعاً تست می‌شود |

گیتِ ادغام (SKILLS_MASTER §6): **هر دو ورک‌فلو باید روی PR سبز باشند.**

## ۶. ران‌بوکِ اجرای دروازه

```bash
node server/seed.js                    # پیش‌نیازِ سوئیت‌های بوت (اگر store نیست، ابزار خودش می‌سازد)
node tools/release-gate.js             # کامل: ایستا + بوتِ واقعی (~۱ دقیقه)
node tools/release-gate.js --skip-boot # سبک، برای چکِ سریعِ CI-بهداشتی
node tools/release-gate.js --json      # خروجی ماشینی (برای صورت‌جلسه/گزارش)
```

قراردادِ خروج: `0` = بدون قرمز (⏳/⚠️ گزارش‌اند، گیتِ سخت نیستند)؛ `1` = دست‌کم یک
گیتِ راستی‌آزمایی‌پذیر قرمز است. ابزار «سبزِ کاذب» را هم می‌گیرد: اگر سوئیتی به هر دلیلی
skip شود (پیامِ «رد شد/موجود نیست»)، همان ردیف **قرمز** می‌شود، نه سبز.
