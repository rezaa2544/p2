# ساختارهای داده و الگوریتم‌ها (data-structures-algorithms)

این مهارت انتخاب و پیاده‌سازی ساختار داده مناسب (لیست، درخت، گراف، جدول هش)
و الگوریتم بهینه (جستجو، مرتب‌سازی، مسیر‌یابی) برای حل مسائل را پوشش می‌دهد.

## When to Use

- هر وقت نیاز به پردازش کارآمد داده در حجم بالا یا حل مسئله محاسباتی
  (جستجو، مرتب‌سازی، پیمایش) داری.
- وقتی کارایی یک مسیر کند شده و باید بررسی کنی ساختار داده مقصر است یا
  الگوریتم.
- Don't use for: داده‌های کوچک که سادگی مهم‌تر از کارایی است.

## Procedure

1. **مسئله را تحلیل کن.** چه عملیاتی روی داده انجام می‌شود؟ (درج، حذف،
   جستجو، پیمایش) داده دینامیک است یا ایستا؟
2. **ساختار مناسب را انتخاب کن:**
   - **آرایه/لیست:** دسترسی تصادفی سریع (O(1))، درج/حذف کند (O(n))
   - **جدول هش (dict/set):** جستجو/درج/حذف میانگین O(1)
   - **درخت جستجوی دودویی / heap:** داده مرتب، عملیات log(n)
   - **گراف:** روابط شبکه‌ای (隣接 list یا matrix)
   - **صف/پشته:** ترتیب خاص پردازش (FIFO / LIFO)
3. **الگوریتم مناسب را انتخاب کن:**
   - جستجوی خطی O(n) / جستجوی دودویی O(log n) — فقط روی داده مرتب
   - مرتب‌سازی: quicksort، mergesort O(n log n)؛ bubble sort O(n²) ممنوع
   - پیمایش گراف: BFS (کوتاه‌ترین مسیر بدون وزن)، DFS (اجزای همبند)
   - جدول برنامه‌نویسی پویا برای زیرمسئله‌های همپوشان
4. **پیچیدگی را تحلیل کن.** زمان و فضای هر ساختار/الگوریتم را یادداشت کن
   و با حجم داده واقعی تطبیق بده.
5. **پیاده‌سازی کن.** از کتابخانه استاندارد استفاده کن مگر اینکه نیاز خاصی
   داری (مثلاً `dict` در پایتون، `Map`/`Set` در JS).
6. **با داده واقعی تست کن.** کارایی را روی حجم داده واقعی پروژه بررسی کن،
   نه فقط داده نمونه.

## Pitfalls

- **استفاده از آرایه برای درج/حذف مکرر** — O(n) هزینه دارد.
- **پیاده‌سازی دستی چیزی که کتابخانه استاندارد دارد** — خطاپذیرتر و
  کندتر.
- **تحلیل پیچیدگی را رد کردن** — کدی که روی ۱۰۰ آیتم خوب کار می‌کند روی
  ۱۰۰٬۰۰۰ آیتم فلج می‌شود.
- **پیچیده‌سازی بی‌جهت:** یک لیست ساده اغلب کافی است.
- **فراموش کردن edge caseها:** داده خالی، یک عنصر، داده تکراری.

## Verification

- الگوریتم روی داده نمونه خروجی درست می‌دهد.
- روی حجم داده واقعی پروژه، در زمان معقول اجرا می‌شود.
- edge caseها (داده خالی، مرتب، معکوس) به‌درستی مدیریت می‌شوند.
- پیچیدگی زمانی/فضایی ثبت شده است.
