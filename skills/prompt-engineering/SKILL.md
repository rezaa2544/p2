# مهندسی Prompt (prompt-engineering)

این مهارت نوشتن و بهینه‌سازی دستورات متنی (prompt) برای تعامل مؤثر با مدل‌های
زبانی را پوشش می‌دهد. هدف این است که از اول تلاش، خروجی مدنظر را با کیفیت
قابل اعتماد دریافت کنی.

## When to Use

- هر بار که می‌خواهی یک LLM (GPT، Claude، Gemini و...) را برای تحلیل، تولید
  متن، کد یا classification به کار بگیری.
- نوشتن system prompt برای یک agent یا chatbot.
- وقتی خروجی مدل نامنظم، نامعتبر یا بیش از حد طولانی است.
- Don't use for: زمانی که خروجی باید قطعی و تکرارپذیر باشد — LLM خروجی
  احتمالی است؛ برای داده‌های حیاتی از کد استفاده کن.

## Prerequisites

- دسترسی به یک LLM (API یا چت).
- شناخت کلی از قابلیت‌ها و محدودیت‌های مدل انتخابی (طول context، ویرایش
  تاریخ cutoff).

## Procedure

1. **هدف را مشخص کن.** یک جمله بنویس: «این prompt دقیقاً چه خروجی‌ای باید
   تولید کند و چه قالبی داشته باشد؟»
2. **ساختار پایه را رعایت کن:**
   - نقش/سیاق (Role): «تو یک مهندس ارشد نرم‌افزار هستی...»
   - وظیفه (Task): «این تابع را بررسی کن...»
   - محدودیت‌ها (Constraints): قالب خروجی، طول، لحن، زبان
   - مثال (Few-shot): ۱ تا ۳ نمونه ورودی/خروجی
3. **قالب خروجی را صریح تعیین کن.** «خروجی را به‌صورت JSON با این schema
   برگردان: ...» یا «یک جدول markdown با این ستون‌ها».
4. **اجرا و مشاهده.** prompt را اجرا کن و خروجی را با هدف تعریف‌شده مقایسه کن.
5. **تکرار کن.** اگر خروجی انحراف داشت: دستور را دقیق‌تر کن، مثال اضافه کن،
   یا محدودیت اضافه کن. از ویرایش قسمت‌های مبهم شروع کن.
6. **اعتبارسنجی.** خروجی را با یک روش مستقل بررسی کن (چک دستی، schema
   validation، یا تست خودکار). هرگز ادعای مدل را بدون بررسی بپذیر.

## Pitfalls

- **دستور کلی و انتزاعی** → خروجی نامشخص. به‌جای «بهبود کن»، بگو «این متغیر
  را به camelCase تبدیل کن».
- **نداشتن مثال صریح** برای قالب‌های غیراستاندارد.
- **درخواست همزمان چند کار نامرتبط** در یک prompt.
- **اعتماد کورکورانه به خروجی** — مدلها hallucinate می‌کنند؛ اعداد،
  ارجاعات و کد را بررسی کن.
- **فراموش کردن فارسی/RTL:** اگر خروجی فارسی است، لحن و دایره واژگان را
  صریح تعیین کن.

## Verification

- خروجی واقعی روی ۳ ورودی نمونه، با هدف تعریف‌شده در مرحله ۱ همخوانی دارد.
- قالب خروجی دقیقاً مطابق درخواست است (JSON معتبر، جدول، یا ساختار دیگر).
- prompt برای یک کار مشابه قابل reuse است.
